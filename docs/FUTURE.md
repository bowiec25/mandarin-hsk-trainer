# Future extensions

Ideas for after v1 (or later milestones), so they don't get lost. Each line says **what**, **why**, and **what already makes it easier**. When one gets planned into a milestone, move it to `docs/PLAN.md` and mark it here.

| Idea | Why | Already makes it easier | Where it would go |
|---|---|---|---|
| **Grader: typo rule can accept the opposite** (found 2026-11-03, M4 Step 4b) | The grader accepts "expensive" for 便宜 (cheap): it's 2 letters from "inexpensive", and long answers allow 2 typos. A prefix like "in-"/"un-" flips the meaning | Grader tests + the judge's eval cases (`tests/data/judge_eval_hsk.jsonl`) show such cases | A grader rule (no typo match that only adds/removes a leading "in"/"un"/"dis"), or a scan of `answers.jsonl` for answer pairs this close |
| **Writer redo keeps banked sentences** (found 2026-11-04, M4 Step 5) | After a `PROMPT_VERSION` bump, `sentence_writer` replaces a word's whole line, so sentences banked from play would be lost | The bank and the writer share `sentences.jsonl` (ADR 0011); every sentence is re-checked on load | Before the next prompt bump: on redo, keep the old sentences that still pass and add the new ones (up to the cap) |
| **Checker: the word inside a harder compound** (found 2026-11-05, first `data-auditor` run) | 一边……一边 passed as a sentence for 边 (band 1): the checker reads 一边 as 一 + 边, so 边 counts as "on its own", though 一边 is a band-3 word. The auditor caught it; the script could too | `sentence_validator` already knows every HSK word and its band (ADR 0009) | If the target word sits inside an HSK word above the band, reject with "has 边 only inside 一边 (band 3)"; add the planted case to the validator's tests |
| **One live retry with the reasons** (found 2026-11-04, M4 Step 5 real play: both of 天's sentences were rejected, 今天天气很好 hides 天 inside 今天/天气 and 我每天都喝牛奶 uses band-2 每) | Fewer words with "no example sentence yet": a rejected live sentence gets one more try, with the checker's reasons, like the batch writer | `write_one` already gets the reasons (`_check_triples` returns them); `build_prompt(rejected=...)` already takes them | Count how often live play gets no sentence (the live log); if it's often, add `retries=1` to `write_one` (about 8 s instead of 4 s for those words) |
| **Missed sentences come back sooner** (added 2026-11-04, ADR 0011) | A banked sentence you got wrong is picked again sooner than "least recently seen" | ADR 0011 tracks when each banked sentence was shown; M5's `progress_store` logs right/wrong | M5: weight the banked pick by past mistakes |
| **Smart "what's next" deck** (added 2026-11-02) | Study what you need: words you often get **wrong** come back more, words seen **recently** wait, words you know well fade out | `deck_builder` is its own block (M3 Step 3), so only it changes; M5's `progress_store` logs every attempt (right/wrong, when) | M5: `progress_store` + Leitner boxes, then a smarter `deck_builder` |
| **Mistake log / stats** (added 2026-11-02) | See your weak words, your accuracy per band, and your progress over time | Same attempt log as above | M5: `hsk stats` |
| ~~**Answer agent**~~ **Done in M4 Steps 3–4a** (added 2026-11-02; play-test 2026-11-02 agreed: "it will need the judgement as opposed to the rules") | Clean answer lists *with synonyms* ("papa" for 爸爸), replacing the hand-written cleaner rules | `answer_writer` wrote `answers.jsonl`; since ADR 0006 it is the quiz's only answer list and the rule cleaner is deleted | Done. Still open: collect wrongly-marked answers while playing as a test set (the judge's cache, Step 4b) |
| ~~**Sentence translation**~~ **Done 2026-11-09** (ADR 0012, issue #54: `translate` / `translate_pinyin`, graded for the gist) (added 2026-11-02; asked again 2026-11-04) | Translate whole sentences, not just words: see the Chinese sentence, type it in English | Since M4 Step 5 every banked sentence has its English (a reference answer), and live sentences come with one; the generic judge (ADR 0007) grades free text | A new mode (e.g. `translate`): show the sentence, read the answer, the judge compares it with the reference English.
